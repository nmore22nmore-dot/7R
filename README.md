# N
منصة فيديو اجتماعية عربية مستقلة بهوية N.

الإعداد:
1. نفّذ supabase/schema.sql في مشروع Supabase.
2. أضف SUPABASE_URL و SUPABASE_PUBLISHABLE_KEY إلى Codemagic.
3. شغّل flutter pub get ثم flutter analyze ثم flutter test ثم flutter build apk --release.

الأسماء:
4 أحرف فأكثر عادية، و3 أحرف أو أقل Premium تحت تحكم Admin.
لا توجد مفاتيح سرية داخل المشروع.

ملاحظة: البث المباشر، المدفوعات والهدايا وبعض خدمات الاتصال تحتاج مزودًا وإعدادًا خارجيًا قبل الإنتاج.
