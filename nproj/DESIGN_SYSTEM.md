# N Design System — v1

## Direction
Dark, premium, cinematic social-video UI. Arabic-first, RTL, high contrast, neon cyan/pink brand accents.

## Brand
- Primary cyan: `#00F2FE`
- Primary pink: `#FF0050`
- Background: `#050607`
- Surface: `#121212`
- Elevated surface: `#1B1B1D`
- White: `#FFFFFF`
- Muted: `#9B9BA1`

## Core screens
1. Home / For You — full-screen video feed.
2. Following.
3. Explore / Search.
4. Create / Upload.
5. Live.
6. Messages.
7. Notifications.
8. Profile.
9. Gifts / Store / Coins.
10. Settings / Safety / Privacy.
11. Moderation / Admin.

## Components added
- `NLogo`
- `NPrimaryButton`
- `NBottomNav`
- centralized colors, sizes, typography, and theme.

## Rule
Feature screens must consume the design tokens instead of hard-coded colors where practical.
