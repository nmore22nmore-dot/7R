# N — Complete Release Candidate 2.1.0

This package consolidates the Phase 28 security baseline with the latest N visual refinements.

## Included
- N dark/cinematic design tokens and centralized colors.
- Home feed refined toward the supplied N reference design.
- Functional For You / Following feed tabs.
- Functional global user search backed by `public_profiles`.
- Video upload, preview, cover selection, publishing and sharing flows from Phase 28.
- Explore, Live, Wallet/Gifts, Messages, Notifications and Profile flows.
- Security & Privacy page with password/session controls, reporting and admin entry.
- Supabase RLS/security schema from Phase 28.
- Android release configuration and Codemagic pipeline from Phase 28.

## Important
The source was structurally checked, but Flutter/Dart CLI is not installed in the current environment, so no local `flutter analyze`, test, or APK build is claimed here. The authoritative verification remains the Codemagic build and on-device QA.
