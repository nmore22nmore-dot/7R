N 5.3.0 final-repair baseline

This archive is the repaired source baseline for Codemagic.
Flutter SDK is not installed in the analysis container, so flutter analyze/test/build were not executed locally.
Codemagic is configured to run pub get, analyze, tests, and release APK build.

Major repairs in this pass:
- Supabase RLS is the source of truth for feed visibility.
- Real 24-hour Stories upload/view flow with private storage and image/video support.
- Real QR generation via qr_flutter.
- Profile visitor and blocked-user screens resolve profile data.
- N AI calls a protected Supabase Edge Function (requires OPENAI_API_KEY secret).
- Post-media storage access now follows the same post visibility/+21/block rules.

5.4.0 integration additions:
- Offline video/image downloads are stored in the app documents directory and exposed in "المشاهدة دون اتصال".
- Live rooms now have persistent comments, realtime comment refresh, viewer counting, host end-live action, and one-active-room-per-host protection.
- Messages now have read receipts/unread badges.
- Coin recharge is wired to Google Play Billing product IDs: n_coins_100, n_coins_550, n_coins_1200, n_coins_2600, n_coins_7000.
- Supabase Edge Function verify-purchase verifies Android purchases with Google Play and credits coins atomically.
External production configuration still required (not a code/build step): deploy the verify-purchase Edge Function, set GOOGLE_SERVICE_ACCOUNT_JSON and GOOGLE_PLAY_PACKAGE_NAME, create the matching Play Console products, set OPENAI_API_KEY for N AI, and provide an actual live streaming provider URL/SDK for broadcaster ingestion. These are service credentials/store/provider configuration, not missing Flutter feature code.


5.4.0 production-hardening pass:
- Protected profile admin/verified fields with server trigger.
- Prevented underage users from changing posts into +21 content.
- Added server-side coin product/amount validation.
- Reworked live viewer accounting to track room/user sessions and prevent arbitrary viewer-count decrements.
- Updated in-app About version to 5.4.0.
