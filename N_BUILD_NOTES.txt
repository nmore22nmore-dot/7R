N 5.0.3 FINAL RELEASE

- Flutter Android source release for the N application.
- Codemagic generates the Android host project when android/ is absent, then runs pub get, analyze, tests and release APK build.
- Required Codemagic environment variables: SUPABASE_URL and SUPABASE_PUBLISHABLE_KEY (group: N_SUPABASE).
- Apply supabase/schema.sql once to the target Supabase project before testing authentication, publishing, messaging and private media.
- Message attachments: up to 50 MB. Post media: up to 200 MB.
- Storage buckets are private and use authenticated access policies.
- Android auth callback: n://auth-callback.
- Local Flutter SDK was not available in the packaging environment, so a local flutter analyze/build could not be executed here; Codemagic performs these gates in CI.
- Final attachment hardening: Android file picking now requests file bytes when available and falls back to a filesystem path, allowing cloud/document-provider selections to upload correctly; message lists refresh even when message count is unchanged; failed message DB inserts clean up the uploaded Storage object.
