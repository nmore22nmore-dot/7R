N 5.1.0 FINAL DESIGN RELEASE

- Updated the internal UI to the requested dark social-video design reference.
- Added rounded floating bottom navigation with Home, Friends, Create, Live, and Profile.
- Refined home/feed controls, live area, publish screen, messages, profile, settings, notifications, wallet/gifts and utility pages.
- Preserved Supabase authentication, posts, follows, comments, storage and messaging flows from the supplied project.
- Preserved the N app name and supplied branding assets.
- Codemagic remains configured to generate the Android host project, run flutter analyze/tests, and build the release APK.
- Required Codemagic group variables: SUPABASE_URL and SUPABASE_PUBLISHABLE_KEY.
- Android auth callback: n://auth-callback.
- The packaging environment used here does not include Flutter SDK, so a local flutter analyze/build could not be executed here. Codemagic is configured to perform those gates.

- 5.2.0: connected previously empty actions: live options/watch, profile share, account/security/about, activity, profile visitors, blocking, creator studio, wallet/gifts, notification loading/mark-read, QR sharing, and RTL home feed.
- Added Supabase tables/policies/functions/triggers for profile views, blocked users, gift transactions, and automatic like/follow/comment/gift notifications.
- Store purchase remains intentionally gated behind a real payment provider; its button now explains the requirement instead of doing nothing.
- N AI remains a UI placeholder until an Edge Function/provider is configured; its send action is connected to a clear response.

Firebase Cloud Messaging integration (2026-09-20):
- Firebase project: rbe-ed3c0 (7RBE)
- Android package: com.n.n_app
- google-services.json is stored at firebase/google-services.json and copied into android/app during Codemagic.
- firebase_core and firebase_messaging are initialized at startup; Android notification permission is requested.
- Do not place Firebase service-account private keys in the app. Server-side FCM sending should be added later through a secure backend/Edge Function.
- FCM push token registration added: authenticated devices store tokens in public.push_tokens.
- Added Supabase Edge Function supabase/functions/send-push for Firebase HTTP v1 delivery using FIREBASE_SERVICE_ACCOUNT_JSON.
- Database webhook still needs to be configured once: notifications INSERT -> send-push Edge Function.
